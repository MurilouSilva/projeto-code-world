# CodeWorld

Portal de página única do projeto CodeWorld, trabalho de Front End de referente a aula de desenvolvimento front end.

## Estrutura

- `index.html` — marcação das 7 seções
- `style.css` — estilo do projeto
- `img/` — imagens; a maioria são placeholders de "?" no tamanho exato de cada slot do design,
  prontos para serem substituídos pela arte final

## Como visualizar

Abra `index.html` diretamente no navegador — não há build nem dependências.
